# Estructura inicial del frontend

Esta carpeta representa únicamente la estructura inicial para una aplicación
web responsive con HTML, CSS y JavaScript, tal como se propone en el RFC.
Todavía no implementa búsqueda, autenticación, detalle, valoraciones ni
recomendaciones.

```text
frontend/
├── index.html              # Punto de entrada de la interfaz
├── css/
│   └── styles.css          # Estilos y diseño responsive
├── js/
│   └── main.js             # Punto de entrada del comportamiento
└── README.md
```

Las pantallas y la comunicación con el backend se desarrollarán en Issues
posteriores, una funcionalidad a la vez, con sus pruebas y Pull Requests.
