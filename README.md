# Sistema de recomendación para libros/comics/manga

Aplicación web de recomendación de libros, comics y manga disponibles en México. El sistema busca facilitar el descubrimiento de nuevas obras mediante recomendaciones basadas en las preferencias y calificaciones de cada usuario.

## Descripción

La gran cantidad de libros, cómics y manga disponibles puede dificultar que los usuarios encuentren contenido relacionado con sus intereses.

Nuestro proyecto propone desarrollar una aplicación web que permita a los usuarios buscar obras, consultar su información, calificarlas y recibir recomendaciones personalizadas.

Las recomendaciones utilizarán información como las preferencias del usuario y características de las obras, por ejemplo, género, autor, temática y etiquetas.

## Funcionalidades

Las funcionalidades consideradas inicialmente para el sistema son:

- Registro e inicio de sesión de usuarios.
- Búsqueda de libros, cómics y manga.
- Consulta de información de las obras.
- Calificación de obras.
- Registro del historial de obras calificadas.
- Generación de recomendaciones personalizadas.
- Consulta de recomendaciones.

Estas funcionalidades podrán ajustarse conforme avance el análisis de requerimientos.

## Sistema de recomendación

El sistema de recomendación buscará identificar las preferencias de cada usuario y recomendar obras con características similares.

Inicialmente se considerarán características como:

- Autor.
- Género.
- Temática.
- Etiquetas (tags).
- Calificaciones del usuario.

Durante el análisis del proyecto se investigarán diferentes estrategias de recomendación, como:

- Filtrado basado en contenido.
- Filtrado colaborativo.
- Sistemas híbridos.

La estrategia final será seleccionada considerando el alcance del proyecto y los datos disponibles.

### HU02 — Calificar una obra

Como usuario, quiero calificar una obra que haya leído para registrar mis preferencias.

### HU03 — Recibir recomendaciones

Como usuario, quiero recibir recomendaciones personalizadas para descubrir nuevas obras que puedan ser de mi interés.

### HU04 — Consultar historial

Como usuario, quiero consultar las obras que he calificado para revisar mis preferencias anteriores.

### HU05 — Consultar información

Como usuario, quiero consultar la información de una obra antes de decidir si quiero leerla.

## Fuentes de datos

Se investigarán diferentes fuentes de información para obtener los datos de libros, cómics y manga.

Entre las alternativas a evaluar se encuentran:

- APIs públicas.

La fuente definitiva se seleccionará después de evaluar la disponibilidad, calidad y condiciones de uso de los datos.
