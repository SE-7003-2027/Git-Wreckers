# Sistema de recomendación para libros/comics/manga

Aplicación web de recomendación de libros, comics y manga disponibles en México. El sistema busca facilitar el descubrimiento de nuevas obras mediante recomendaciones basadas en las preferencias y calificaciones de cada usuario.

## Descripción

La gran cantidad de libros, comics y manga disponibles puede dificultar que las personas encuentren contenido relacionado con sus intereses.

Este proyecto propone una plataforma donde los usuarios podrán buscar obras, consultar su información, calificarlas y recibir recomendaciones personalizadas. Las recomendaciones podrán organizarse utilizando características como el autor, el género y el estado de publicación.
